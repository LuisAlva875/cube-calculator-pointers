# Cube Calculator Using Pointers

A console-based application that calculates the cube of an integer using pointers and function parameter passing.

## Overview

This project demonstrates how pointers can be used to pass variables by reference to a function.

The program requests an integer from the user, passes its memory address to a function, and calculates the cube of the value through pointer dereferencing.

## Features

- User input.
- Function parameter passing using pointers.
- Integer cube calculation.
- Console-based interface.
